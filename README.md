# 🧙 The One Bot

A simple **Python Discord bot** that integrates with [The One API](https://the-one-api.dev/) to fetch and display information about **J.R.R. Tolkien's Middle-earth**.

## ✨ Features

* 🔎 Search for characters and quotes
* 📜 Fetch data directly from The One API
* 🤖 Discord slash commands
* ⚡ Asynchronous API requests
* 🧩 Clean separation between Discord and API logic

## 🛠️ Tech Stack

* **Python**
* **Discord.py**
* **The One API**

## 📖 Usage

```text
/characters                     Displays information about all characters.
/character <character-name>     Displays information about the given character.

/quotes                         Displays up to 10 quotes with pagination.
/quotes <character-name>        Displays up to 10 quotes from the given character with pagination.
```
